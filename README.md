## Neden bu çukur?

- Adayın adresi sabittir. Taşınmaz.
- Seçim otobüsü gerekmez; seçmen zaten üzerinden geçer.
- Vaadi somuttur: sizi yutmak.
- Hiçbir koalisyona girmez. Zaten her şey ona girer.

## Kurulum

```bash
python3 kampanya.py
```

Bağımlılık yoktur. Çukur kendi kendine yeter.

## Ne yapar?

1. Rastgele ama resmi bir miting konuşması üretir.
2. Seçim vaadi listesi basar.
3. Hayali oy sayımı yapar (sandık: çukurun dibi).
4. Kayyum onay mührünü basar.
